# Ersatztv pictures

This repository is intended to hold image assets you can use with Ersatztv.

## Suggested layout

- `images/` — general channel art, logos, and backgrounds
- `images/channel/` — per-channel images
- `images/icons/` — small icons or overlays

## Recommended image types

- JPG / PNG for photos and backgrounds
- SVG for logos and simple graphics
- Keep file names descriptive and lowercase
- Use a consistent size for channel logos and banners

## Using images in Ersatztv

Once files are committed to GitHub, use the raw file URL in Ersatztv when configuring channel artwork, branding, or backgrounds.

Example:

`https://raw.githubusercontent.com/weordie/erSatzTV-pics/main/images/example-logo.svg`
